# 📝 ملاحظات المدرب — Trainer Notes

تطبيق PWA لتسجيل ملاحظات المتدربين للمعلمين والمدربين — يعمل **دون إنترنت 100%** وقابل للتثبيت كتطبيق على أي جهاز.

## الميزات
- 👤 ملفات متعددة للمدربين — كل مدرب يرى بياناته فقط
- 🧑‍🎓 المتدربون (الاسم + الرقم التدريبي/الجامعي + المستوى)
- 📚 المقررات (الاسم + الرقم المرجعي + الفصل الدراسي)
- 🏷️ تصنيفات رئيسية وفرعية + **إنشاء تصنيف فوري من داخل نموذج الملاحظة**
- 📎 إرفاق صور وفيديو وصوت + **تسجيل صوتي مباشر** من النموذج
- 📥 استيراد ذكي لملفات «ملخص قائمة المسجلين» من نظام الكلية (xls/xlsx/csv) مع معاينة ومنع تكرار
- 🔍 بحث فوري وفلترة مجمّعة (متدرب/مقرر/تصنيف/فترة)
- ⬇️ تصدير Excel + نسخ احتياطي JSON كامل شامل الوسائط
- 📴 أوفلاين بالكامل (IndexedDB + Service Worker)

## التشغيل
```bash
npm install
npm run dev        # تطوير: http://localhost:5173
npm run build      # بناء الإنتاج إلى dist/
npm run preview    # معاينة الإنتاج: http://localhost:4173
npm test           # اختبارات محلل الاستيراد
```

## النشر على GitHub Pages
المشروع جاهز للنشر مباشرة على GitHub Pages. بعد رفعه إلى مستودع GitHub:

1. افتح إعدادات المستودع: `Settings > Pages`.
2. اختر `Build and deployment > Source > GitHub Actions`.
3. ارفع أي تعديل إلى فرع `main` أو `master`.

سيعمل ملف `.github/workflows/deploy.yml` تلقائياً على تثبيت الحزم، بناء التطبيق، ونشر مجلد `dist` على GitHub Pages. أي تعديل مباشر من موقع GitHub ثم حفظه في الفرع سيعيد نشر التطبيق تلقائياً.

## الاستيراد الذكي
يتعرف تلقائياً على بنية تصدير النظام: كتلة معلومات المقرر أعلى الملف (اسم المقرر / الرقم المرجعي / الفصل الدراسي) ثم جدول الطلاب (`اسم الطالب | الرقم الجامعي | ... | المستوى`). نموذج ملف مرجعي في `samples/`.

## ملاحظات
- البيانات محلية على الجهاز (IndexedDB) — استخدم النسخ الاحتياطي من الإعدادات دورياً.
- النسخة الكاملة تحفظ تواريخ الإنشاء وآخر تعديل، المرفقات، التصنيفات، وإعدادات المدرب. لنقلها إلى متصفح أو هاتف آخر: نزّل «نسخة كاملة» ثم استخدم «استعادة نسخة» في المتصفح الآخر.
- لا توجد مزامنة سحابية تلقائية حالياً؛ إضافتها تحتاج خدمة تخزين وحساب دخول حتى لا تُنقل بيانات المتدربين بلا حماية.
- تظهر المقررات ضمن مجلدات حسب الفصل الدراسي من صفحة المقررات.
- للاستخدام دون إنترنت: افتح الموقع مرة واحدة مع توفر الإنترنت، ثم اختر «تثبيت التطبيق» من المتصفح وافتحه من أيقونته. لا يحتاج بعدها إلى الإنترنت، ما دمت لا تمسح بيانات المتصفح.
- لا يرسل التطبيق بيانات الملاحظات إلى أي خادم، وسياسة الأمان تمنع تحميل الموارد من نطاقات خارجية.
- الروابط العميقة: `#/notes` `#/note-form` `#/trainees` `#/courses` `#/categories` `#/import` `#/settings`
- المزامنة السحابية بين الأجهزة مرحلة لاحقة اختيارية.
